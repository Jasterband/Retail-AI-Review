# B · 样例与数据整理说明

## 大讲堂：同 ID 合格包 vs 不合格包（图片不同）

`零售照片ai审核/药师大讲堂/` 下两套目录场次号有重叠，**不要当成同一份照片**：

| 包 | 路径 | 含义 |
|----|------|------|
| 合格 50 场 | `大讲堂已上传过的50场会议核销资料/` | 含 20 场**换图后**的合格版 + 另外 30 场 |
| 不合格 20 场 | `20场有不合格照片场次&对应执行报告/`（新不合格包） | 同 20 个 ID 的**换图前**不合格版；错误明细见目录内 `照片错误明细.xlsx` |

- 20 场 ID 全部落在 50 场集合内，但问题材料（错误明细中的展架/讲者/海报/全景等）字节内容不同。
- 构造负样本 / 跑回归时：FAIL 用例读不合格包；PASS 用例读 50 场包——**不要混用同 ID 的另一套图**。
- 可视化对比：`零售照片ai审核/药师大讲堂/换图对比-不合格20vs合格50.html`
- 更完整口径见 [05-golden-set.md · 本地样本库](../05-golden-set.md)
