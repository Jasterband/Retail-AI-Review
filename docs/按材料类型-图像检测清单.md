# 按材料类型 · 图像检测清单

> 图上要检什么：单张 `checks` + 相关场级 `rule_results`。  
> 契约细节见 [检测点清单与photo_results.md](检测点清单与photo_results.md)；规则阈值见 [03-rule-matrix.md](03-rule-matrix.md)。

**一眼记：**  
图上无非几类事——**类别 / 清晰度、Logo、OCR 字段对表单、模版特征、人数、签到时长门店、跨会盗图、讲者主题查重**；再按材料类型开关适用项。

## 1. 几乎每张图（通用）

| 检什么 | 检测点 | 说明 |
|--------|--------|------|
| 材料类型 | `photo_type` / `type_match` | **以 PE 传入的 `photo_type` 为准**，不做视觉分类；`type_match` 恒为 true |
| 清不清晰 | `is_clear` / `clarity_score` | **本地 Laplacian 方差**映射 0~1，默认 ≥0.60 为清 |
| 是否盗用他场照片 | `image_not_duplicated` | 跨会 pHash + embedding；**不查会内** |

场级对应：`ASSET_TYPE_CHECK`（直接 PASS，信任 PE）、`CLARITY`、`IMAGE_DUP`。

### 1.1 通用检测逻辑说明

| 检测点 | Detect 手段 | 本质 |
|--------|-------------|------|
| 类型 | PE 请求体 `photos[].photo_type` | **不调模型** |
| `is_clear` | 本地 Laplacian 方差 → `clarity_score` | 像素锐度，**不调模型** |
| `image_not_duplicated` | 本地 pHash + embedding ↔ 历史库 | 图像指纹，**不调模型** |

流水线：

```text
下载图
  ├─ compute_phash / compute_image_embedding
  │     → 与 image_dup_history（其他会议）比对
  │     → image_not_duplicated / 场级 IMAGE_DUP
  ├─ compute_clarity_score（Laplacian 方差 → 0~1）
  │     → is_clear = (score ≥ clarity_threshold)
  └─ Vision.analyze（图 + prompt，按 PE 声明类型做 OCR/特征抽取 → JSON）
```

#### （1）类别（不做视觉识别）

1. PE 在请求里声明本张 `photo_type`（如 `Poster`）。
2. 审核侧**不再**让 Vision 返回 `detected_type`，也不比对「声明 vs 识别」。
3. 单张 `type_match=true`；场级 `ASSET_TYPE_CHECK` 固定 PASS（说明：以 PE 声明为准）。
4. Prompt 仍会带上声明类型，只用于指导「按该类型抽字段」，不是分类任务。

#### （1b）关键字段 OCR（海报/展架/电子日程）

1. 模版 pack 存「会议时间 / 地点 / 日程表」参考 **crop**（`poster_*_crop.jpg` / `edm_key_fields_crop.jpg`）。
2. 新图上做多尺度 **NCC 定位** → 得到字段区框。
3. **裁出 ROI** 后再调 Vision 只抽 `meeting_date` / `start_time` / `end_time` / `meeting_location` / `speaker_names`。
4. 合并进 `ocr_fields`，再算 `date_matches_form` 等 checks。  
   实现：`app/services/field_roi_ocr.py`（流水线 step `field_roi_ocr`）。

#### （2）清晰度 `is_clear` / `clarity_score`

1. **本地算法**（`app/services/clarity_util.py`）：灰度图 3×3 Laplacian 方差，再经 log10 + sigmoid 映射到 0~1。
2. **不依赖 Vision**：模型估分不稳定（JSON 失败时还会变成 null →「未判定」），故已从 prompt 去掉 `clarity_score`。
3. 有字节即可出分；解码失败才为 null。
4. `is_clear = clarity_score >= clarity_threshold`（默认 **0.60**，可用 `options.clarity_threshold` 覆盖）。
5. 场级 `CLARITY`：有图低于阈值 → **UNCERTAIN**（一般不单独硬 FAIL）；模糊图会让依赖它的 OCR/模版类规则更保守。

标定参考：验收对照样清晰图多在 0.65~0.95；对清晰原图加重度高斯模糊（半径 ≥8）通常落到阈值以下。

#### （3）盗用 `image_not_duplicated`（跨会）

**不经过 Vision。** 流程：

1. 下载图片字节后本地算：
   - **pHash**（`phash_util`）：灰化 → 缩 32×32 → DCT 低频 → 中值二值化 → hex 指纹。
   - **embedding**（`embedding_util`）：24×24 灰度缩略图 + RGB 直方图 → L2 归一化向量（纯 Pillow，无额外 ML）。
2. 与表 `image_dup_history` 中**其他 `meeting_id`** 比对（默认再按 `period_id` 限同期）；**不查本场内部**两张图是否相似。
3. 命中条件（满足其一即可）：
   - pHash 汉明距离 ≤ `image_phash_max_distance`（默认 **10**）→ 优先；`kind=exact`（距离 0）或 `similar`；
   - 否则 embedding 余弦相似度 ≥ `image_similarity_threshold`（默认 **0.92**）→ `kind=similar`。
4. 单张：`image_not_duplicated = not 命中`；场级命中 → `IMAGE_DUP` FAIL。
5. 本场审完后把 phash + embedding 写入 history，供后续场次比对。
6. 历史库为空（首场）→ `IMAGE_DUP` SKIP。

**改图鲁棒性（经验）：**

| 改动 | 大致能否检出 |
|------|----------------|
| 压缩 / 调亮度 | 多数能（pHash 或 embedding） |
| 轻度裁剪（约 10%） | 常靠 embedding 兜住；纯 pHash 可能漏 |
| 较大裁剪（约 30%+）/ 裁半 | 容易漏 |
| 轻度仿射扭曲 | 多数能 |
| 强液化 / 大幅变形 | 容易漏（需更强 CLIP 类模型） |

阈值见 [thresholds.md](thresholds.md)。

## 2. 大讲堂 · 海报 / 展架 / 电子日程

材料类型：`Poster` / `Stand` / `EDM`

| 检什么 | 检测点 |
|--------|--------|
| 拜耳 Logo | `has_bayer_logo` |
| 日期 vs 表单 | `date_matches_form` |
| 时间 vs 表单 | `time_matches_form` |
| 地点 vs 表单 | `location_matches_form` |
| 讲者名 vs 表单 | `speakers_match_form` |
| 水印（若有） | OCR `watermark_*` → 场级 `WATERMARK_CONSISTENCY` |

场级汇总：`BAYER_LOGO`、`KEY_FIELD_MATCH`、`TIME_CONSISTENCY`、`WATERMARK_CONSISTENCY`。

## 3. 大讲堂 · 台卡

材料类型：`TableCard`

| 检什么 | 检测点 |
|--------|--------|
| 台卡人数 = 讲者人数（通常 4） | `name_card_count_ok` |
| OCR 姓名集合 = `form.speakers` | `name_set_matches_speakers` |
| 版式像规定台卡模版 | `name_card_template_ok` |

场级：`NAME_CARD_SPEAKER_MATCH`、`NAME_CARD_TEMPLATE`。

姓名检测流程（与海报字段 ROI 同思路）：

1. 模版 pack 存单张台卡参考 crop（`name_card_one_roi.jpg`）。
2. 用参考 crop **对照 Vision 标出各卡框**；失败再多实例 NCC；姓名仍不足时用 **2×2 网格**兜底。
3. 逐张裁 ROI 后再调 Vision 只抽姓名 → 合并为 `name_card_names`。
4. 实现：`app/services/field_roi_ocr.py`（`_enrich_name_cards`，同属 step `field_roi_ocr`）。

## 5. 大讲堂 · 讲者照

材料类型：`SpeakerTitle` / `SpeakerLecture`（`photo_type` 已声明合影/讲课；不再使用 `speaker_shot_kind`）

| 检什么 | 检测点 |
|--------|--------|
| 标题合影：课件标题 vs 该讲者 `topic` | `topic_matches_form`（仅 `SpeakerTitle`） |
| 标题是否与历史场次重复 | `topic_not_reused_in_period` |
| 能否对上正确讲者 | `speaker_name_visible_ok` |
| 每位是否两类照齐全 | 场级 `SPEAKER_SHOT_PAIR`（各 ≥1 张 `SpeakerTitle` + `SpeakerLecture`） |

场级另有：`SPEAKER_TOPIC_OCR`、`TOPIC_REUSE`。

## 6. 全景

材料类型：`Panorama`

| 检什么 | 检测点 |
|--------|--------|
| 本张人数能否读出 | `people_count_recorded`（人数在 `people_count`） |
| 合计是否达标 | 场级 `PANORAMA_COUNT`：大讲堂 ≥35；微型单 ≥6 / 双 ≥12 |
| 水印（若有） | 同通用水印 → `WATERMARK_CONSISTENCY` |

> 是否达标按**多张合计**在场级判，不要单张硬判 false。

## 11. 场级汇总（多图一起判）

不在单张 `checks` 里硬判；看 `rule_results`。

| 规则 | 看什么 |
|------|--------|
| `ASSET_MISSING` | 必传材料能否读到 |
| `ASSET_TYPE_CHECK` | 信任 PE 声明类型（不做视觉分类） |
| `CLARITY` | 清晰度汇总 |
| `KEY_FIELD_MATCH` | 多图字段交叉 vs form |
| `TIME_CONSISTENCY` | 多图时间是否一致 |
| `BAYER_LOGO` | 应检材料是否都有 Logo |
| `PANORAMA_COUNT` | 全景人数合计阈值 |
| `SIGNIN_DURATION` | 签到时长阈值 |
| `IMAGE_DUP` | 跨会盗图（pHash + embedding） |
| `TOPIC_REUSE` | 讲者照标题跨会重复 |
| `WATERMARK_CONSISTENCY` | 水印日期/地点/时间 |
| 大讲堂专属 | `NAME_CARD_*`、`HANDBOOK_*`、`SPEAKER_SHOT_PAIR`、`SPEAKER_TOPIC_OCR` |
| 微型专属 | `PPT_TEMPLATE_MATCH`、`PPT_PAGE_KIND`、`SIGNIN_RATIO_AND_STORES` |
