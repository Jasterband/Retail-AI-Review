# 按材料类型 · 图像检测清单

对齐根目录《按材料类型-图像检测清单_枚举检测点》；`flag_reason_code` 为 PE `fail_reasons[].reason_code`。

「对台账」列打 **✓** = 须与 PE 会议表单 / 讲者台账比对。

注：
1. 日程海报、展架及签到表手写不清时，识别结果需重点核查。
2. 照片模糊、遮挡或全景人员密集会影响准确率。
3. **同场次多张全景取单张人数最大值，不累加。**
4. 除全景外，同场次同类材料任一照片任一适用检测点不合格 → 该类材料不合格。
