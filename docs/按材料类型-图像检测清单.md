## 1. 几乎每张图（通用）

| 检什么 | 检测点 | 说明 |
|--------|--------|------|
| 类别对不对 | `type_match` | 声明 `asset_type` vs Vision `detected_type` |
| 清不清晰 | `is_clear` / `clarity_score` | Vision 估分，默认 ≥0.60 为清 |
| 是否盗用他场照片 | `image_not_duplicated` | 跨会 pHash + embedding；**不查会内** |

场级对应：`ASSET_TYPE_CHECK`、`CLARITY`、`IMAGE_DUP`。

### 1.1 通用检测逻辑说明

三类通用检测的入口不同：

| 检测点 | Detect 手段 | 本质 |
|--------|-------------|------|
| `type_match` | Vision 多模态看图 → `detected_type` | 模型分类 |
| `is_clear` | Vision 多模态看图 → `clarity_score` | 模型打分 |
| `image_not_duplicated` | 本地 pHash + embedding ↔ 历史库 | 图像指纹，**不调模型** |

流水线：

```text
下载图
  ├─ compute_phash / compute_image_embedding
  │     → 与 image_dup_history（其他会议）比对
  │     → image_not_duplicated / 场级 IMAGE_DUP
  └─ Vision.analyze（图 + prompt → JSON）
        ├─ detected_type  → type_match = (detected == declared)
        └─ clarity_score  → is_clear   = (score ≥ clarity_threshold)
```

#### （1）类别 `type_match`

1. PE 声明本张 `asset_type`（如 `POSTER`）。
2. 调用 Vision（OpenAI 兼容 `/chat/completions`，带 `image_url`）：prompt 要求返回 `detected_type`（英文枚举）+ `type_confidence`。
3. 本地比较：`detected_type == declared_type` → `type_match=true`；识别不出 → `null`。
4. 场级 `ASSET_TYPE_CHECK`：不一致且置信度 ≥ `human_confidence_threshold`（默认 0.75）→ FAIL；置信度低 / 无类型 → UNCERTAIN。PDF 签到跳过视觉分类。

**没有**单独的分类网络；类别完全靠多模态 JSON 字段。相关 prompt：`app/services/vision/prompts.py`（System 要求 `detected_type` 用英文枚举；Schema 列出可选类型）。

#### （2）清晰度 `is_clear` / `clarity_score`

1. **同一轮** Vision 请求中要求返回 `clarity_score`（0~1）。
2. **不是** OpenCV 拉普拉斯 / FFT 等传统清晰度算法，是模型主观估分。
3. Prompt **未写**「怎样算清晰/模糊」的细则，仅约定 `clarity_score 为 0~1`；模型凭训练常识打分，可能有波动。
4. 本地：`is_clear = clarity_score >= clarity_threshold`（默认 **0.60**，可用 `options.clarity_threshold` 覆盖）。
5. 场级 `CLARITY`：有图低于阈值 → **UNCERTAIN**（一般不单独硬 FAIL）；模糊图会让依赖它的 OCR/模版类规则更保守。

若要可控，需在 `prompts.py` 补清晰度评分细则（如：主体失焦/糊字 → 低分；文字锐利可读 → 高分）。

#### （3）盗用 `image_not_duplicated`（跨会）

**不经过 Vision。** 流程：

1. 下载图片字节后本地算：
   - **pHash**（`phash_util`）：灰化 → 缩 32×32 → DCT 低频 → 中值二值化 → hex 指纹。
   - **embedding**（`embedding_util`）：24×24 灰度缩略图 + RGB 直方图 → L2 归一化向量（纯 Pillow，无额外 ML）。
2. 与表 `image_dup_history` 中**其他 `meeting_id`** 比对（默认再按 `period_id` 限同期）；**不查本场内部**两张图是否相似。
3. 命中条件（满足其一即可）：
   - pHash 汉明距离 ≤ `image_phash_max_distance`（默认 **10**）→ 优先；`kind=exact`（距离 0）或 `similar`；
   - 否则 embedding 余弦相似度 ≥ `image_similarity_threshold`（默认 **0.92**）→ `kind=similar`。
4. 单张：`image_not_duplicated = not 命中`；场级命中 → `IMAGE_DUP` FAIL。
5. 本场审完后把 phash + embedding 写入 history，供后续场次比对。
6. 历史库为空（首场）→ `IMAGE_DUP` SKIP。

**改图鲁棒性（经验）：**

| 改动 | 大致能否检出 |
|------|----------------|
| 压缩 / 调亮度 | 多数能（pHash 或 embedding） |
| 轻度裁剪（约 10%） | 常靠 embedding 兜住；纯 pHash 可能漏 |
| 较大裁剪（约 30%+）/ 裁半 | 容易漏 |
| 轻度仿射扭曲 | 多数能 |
| 强液化 / 大幅变形 | 容易漏（需更强 CLIP 类模型） |

阈值见 [thresholds.md](thresholds.md)。

## 2. 大讲堂 · 海报 / 展架 / 电子日程

材料类型：`POSTER` / `STAND` / `E_POSTER`

| 检什么 | 检测点 |
|--------|--------|
| 拜耳 Logo | `has_bayer_logo` |
| 日期 vs 表单 | `date_matches_form` |
| 时间 vs 表单 | `time_matches_form` |
| 地点 vs 表单 | `location_matches_form` |
| 讲者名 vs 表单 | `speakers_match_form` |
| 水印（若有） | OCR `watermark_*` → 场级 `WATERMARK_CONSISTENCY` |

场级汇总：`BAYER_LOGO`、`KEY_FIELD_MATCH`、`TIME_CONSISTENCY`、`WATERMARK_CONSISTENCY`。

## 3. 大讲堂 · 台卡

材料类型：`NAME_CARD`

| 检什么 | 检测点 |
|--------|--------|
| 台卡人数 = 讲者人数（通常 4） | `name_card_count_ok` |
| OCR 姓名集合 = `form.speakers` | `name_set_matches_speakers` |
| 版式像规定台卡模版 | `name_card_template_ok` |

## 5. 大讲堂 · 讲者照

材料类型：`SPEAKER_PHOTO`

| 检什么 | 检测点 |
|--------|--------|
| 合影 / 讲课类型是否与声明一致 | `speaker_shot_kind_ok`（`TITLE_GROUP` / `LECTURING`） |
| 标题合影：课件标题 vs 该讲者 `topic` | `topic_matches_form`（仅 TITLE_GROUP） |
| 标题是否与历史场次重复 | `topic_not_reused_in_period` |
| 能否对上正确讲者 | `speaker_name_visible_ok` |
| 每位是否两类照齐全 | 场级 `SPEAKER_SHOT_PAIR` |

场级另有：`SPEAKER_TOPIC_OCR`、`TOPIC_REUSE`。

## 6. 全景

材料类型：`PANORAMA`

| 检什么 | 检测点 |
|--------|--------|
| 本张人数能否读出 | `people_count_recorded`（人数在 `people_count`） |
| 合计是否达标 | 场级 `PANORAMA_COUNT`：大讲堂 ≥35；微型单 ≥6 / 双 ≥12 |
| 水印（若有） | 同通用水印 → `WATERMARK_CONSISTENCY` |

> 是否达标按**多张合计**在场级判，不要单张硬判 false。

## 7. 签到表

## 11. 场级汇总（多图一起判）

不在单张 `checks` 里硬判；看 `rule_results`。

| 规则 | 看什么 |
|------|--------|
| `ASSET_MISSING` | 必传材料能否读到 |
| `ASSET_TYPE_CHECK` | 类型汇总 |
| `CLARITY` | 清晰度汇总 |
| `KEY_FIELD_MATCH` | 多图字段交叉 vs form |
| `TIME_CONSISTENCY` | 多图时间是否一致 |
| `BAYER_LOGO` | 应检材料是否都有 Logo |
| `PANORAMA_COUNT` | 全景人数合计阈值 |
| `SIGNIN_DURATION` | 签到时长阈值 |
| `IMAGE_DUP` | 跨会盗图（pHash + embedding） |
| `TOPIC_REUSE` | 讲者照标题跨会重复 |
| `WATERMARK_CONSISTENCY` | 水印日期/地点/时间 |
| 大讲堂专属 | `NAME_CARD_*`、`HANDBOOK_*`、`SPEAKER_SHOT_PAIR`、`SPEAKER_TOPIC_OCR` |
| 微型专属 | `PPT_TEMPLATE_MATCH`、`PPT_PAGE_KIND`、`SIGNIN_RATIO_AND_STORES` |
