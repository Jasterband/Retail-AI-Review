# 按材料类型 · 图像检测清单

「对台账」列打 **✓** = 须与 PE 会议表单 / 讲者台账比对。

---

## 一、药师大讲堂（LECTURE_HALL）

最少张数（典型 4 讲者 = 15）：`EDM`×1 · `Poster`×1 · `Stand`×1 · `TableCard`×1 · `Manual`×1 · `SpeakerTitle`×每人1 · `SpeakerLecture`×每人1 · `Panorama`≥1 · `SignSheet`≥1

### 1. 电子日程海报 / 日程海报 / 日程展架（`EDM` / `Poster` / `Stand`）— 6 点

| # | 检测点 | 对台账 | 含义 |
|---|--------|:------:|------|
| 1 | `image_not_duplicated` |  | 本照片是否和其他场次照片重复（无人物；仅完全一致） |
| 2 | `has_bayer_sponsor` |  | 图最下方是否出现赞助方「拜耳医药保健有限公司」 |
| 3 | `date_matches_form` | ✓ | 日期是否和表单一致 |
| 4 | `time_matches_form` | ✓ | 时间是否和表单一致 |
| 5 | `location_matches_form` | ✓ | 地点是否和表单一致 |
| 6 | `speakers_match_form` | ✓ | 讲者名是否和表单一致 |

### 2. 台卡（`TableCard`）— 2 点

| # | 检测点 | 对台账 | 含义 |
|---|--------|:------:|------|
| 1 | `name_card_count_ok` | ✓ | OCR 姓名数 = 台账讲者人数 |
| 2 | `name_set_matches_speakers` | ✓ | 姓名集合是否和表单一致 |

> 台卡不参与 `IMAGE_DUP`。

### 3. 手册（`Manual`）— 3 点

| # | 检测点 | 对台账 | 含义 |
|---|--------|:------:|------|
| 1 | `image_not_duplicated` |  | 本照片是否和其他场次照片重复（含近似） |
| 2 | `handbook_detected` |  | 是否存在菁英药师大讲堂宣传手册封面 |
| 3 | `handbook_not_stale` |  | 手册是否为当期版本 |

### 4. 讲者标题合影（`SpeakerTitle`）— 8 点 / 人

| # | 检测点 | 对台账 | 含义 |
|---|--------|:------:|------|
| 1 | `image_not_duplicated` |  | 未盗用他场有人物材料（含近似） |
| 2 | `speaker_title_composition_ok` |  | 同时有讲者 + 标题 + 讲者姓名 + 日期 |
| 3 | `has_speaker_person` |  | 有讲者本人 |
| 4 | `has_topic_title` |  | 有讲题标题 |
| 5 | `topic_matches_form` | ✓ | 标题是否和表单一致 |
| 6 | `has_speaker_name` |  | 有讲者姓名 |
| 7 | `speaker_name_visible_ok` | ✓ | 姓名是否和表单一致 |
| 8 | `has_date` |  | 有日期 |

### 5. 讲者授课照（`SpeakerLecture`）— 4 点 / 人

| # | 检测点 | 对台账 | 含义 |
|---|--------|:------:|------|
| 1 | `image_not_duplicated` |  | 未盗用他场有人物材料（含近似） |
| 2 | `has_speaker_person` |  | 有讲者本人 |
| 3 | `has_ppt_screen` |  | 有 PPT/投影 |
| 4 | `speaker_lecture_composition_ok` |  | 人 + PPT 同时具备 |

### 6. 全景（`Panorama`）— 2 点

| # | 检测点 | 对台账 | 含义 |
|---|--------|:------:|------|
| 1 | `image_not_duplicated` |  | 未盗用他场有人物材料（含近似） |
| 2 | `people_count_recorded` |  | 本张人数可读；场级合计 ≥35 |

### 7. 签到表（`SignSheet`）— 4 点

| # | 检测点 | 对台账 | 含义 |
|---|--------|:------:|------|
| 1 | `duration_readable` |  | 起止时间可读（读不出按模糊） |
| 2 | `duration_meets_threshold` |  | 时长 >120 分钟 |
| 3 | `signin_complete_ok` |  | 本页填写完整（除「其他」列外） |
| 4 | `signin_audience_ok` |  | 多页合计人数 ≥35 |

> 签到表不参与 `IMAGE_DUP`。
